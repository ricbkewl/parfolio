# CoachMe — future feature checklist

Status: Deferred. Rick requested this checklist on October 12, 2026; implementation is not part of the current build work.

Goal: Add a CoachMe button during a round to offer practical shot advice from the tee, fairway, rough, bunker, around the green, or on the green.

## First release

- [ ] Add CoachMe to the playing screen without interfering with scoring or map controls.
- [ ] Use the current ball position, GPS accuracy, hole, chosen target and verified course geometry.
- [ ] Let the golfer confirm or correct ball position, lie and target before requesting advice.
- [ ] Collect personal club carry distances and typical shot tendency; clearly label any estimates.
- [ ] Recommend a club, aiming/landing target and one simple execution cue.
- [ ] Offer a safer alternative when supported by known hazards and the golfer's distances.
- [ ] Tailor guidance to tee shots, approach shots, rough, bunkers and short-game situations.
- [ ] Show uncertain or missing inputs and ask for a distance when course mapping is unverified.
- [ ] Keep advice short and easy to read outdoors; provide a useful fallback if AI or connectivity fails.

## Later enhancements

- [ ] Optional spoken advice with mute and replay controls.
- [ ] Optional ball/lie photo, with consent and clear image-retention controls.
- [ ] Wind and elevation adjustments only when reliable data is available; show its freshness and limitations.
- [ ] Putting guidance based on golfer-provided distance and slope initially.
- [ ] Detailed putting-break recommendations only after dependable green-slope data is available and validated.
- [ ] Personalize recommendations using actual shot outcomes with the golfer's consent.

## Readiness checks before launch

- [ ] Verify applicable golf rules and provide a competition mode that disables restricted advice/features.
- [ ] Validate shot recommendations with a qualified golf coach and on-course testing.
- [ ] Test weak GPS, stale locations, incorrect lie selections, missing hazards and incomplete course maps.
- [ ] Distinguish coaching suggestions from measured facts; avoid promising a particular shot result.
- [ ] Review location/photo privacy, AI cost per round, response time and usage limits.
- [ ] Confirm CoachMe does not degrade map stability, battery life or hole transitions.

Initial priority: club selection, target choice and one execution cue. Reliable putting reads are a separate milestone. This checklist does not authorize subscriptions or change the current mapping-machine priorities.
